# LifeSim-AI

LifeSim-AI is an interactive AI-powered life simulation application built using Python and Streamlit.

## Features

- Interactive life simulation
- AI-generated scenarios and outcomes
- User decision-based simulations
- Simple and user-friendly Streamlit interface
- Real-time simulation results

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Git & GitHub
